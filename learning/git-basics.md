# Основы Git

**Дата:** 2026-09-16
**Источник:** [[2026-s1-lab-01-git]]

## Что изучил

Базовые концепции системы контроля версий Git и практическая работа с локальным репозиторием.

## Ключевые команды

### Инициализация и настройка
```bash
git init                          # создать новый репозиторий
git config user.name "Name"       # настроить имя
git config user.email "email"     # настроить email
```

### Базовые операции
```bash
git status                        # проверить состояние репозитория
git add <file>                    # добавить файл в индекс
git commit -m "message"           # создать коммит
git log                           # просмотреть историю
```

### Работа с ветками
```bash
git branch <name>                 # создать ветку
git checkout <branch>             # переключиться на ветку
git merge <branch>                # слить ветку
git branch -d <name>              # удалить ветку
```

## Концепции

### Три состояния файлов
1. **Modified** - изменен, но не добавлен в индекс
2. **Staged** - добавлен в индекс, готов к коммиту
3. **Committed** - сохранен в локальной базе данных

### Ветки
- Ветка - это подвижный указатель на коммит
- `master`/`main` - основная ветка по умолчанию
- Ветки позволяют работать над разными версиями кода параллельно

### Конфликты слияния
- Возникают когда одни и те же строки изменены в разных ветках
- Требуют ручного разрешения
- Git помечает конфликтные области в файле

## .gitignore

Файл для исключения файлов из отслеживания:
```
*.log
*.tmp
node_modules/
.env
```

## Практические выводы

- Коммиты должны быть атомарными и осмысленными
- Ветки - мощный инструмент для параллельной работы
- Конфликты - нормальная часть работы с Git
- .gitignore помогает держать репозиторий чистым
