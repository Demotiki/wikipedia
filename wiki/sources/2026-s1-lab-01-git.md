# Лабораторная работа №1: Основы Git

## Описание

Лабораторная работа по основам системы контроля версий Git. Включает создание репозитория, работу с коммитами, ветками и разрешение конфликтов слияния.

## Основные темы

- Инициализация Git-репозитория
- Базовые команды Git (add, commit, status, log)
- Работа с ветками (branch, checkout, merge)
- Разрешение конфликтов слияния
- Структура проекта и .gitignore
